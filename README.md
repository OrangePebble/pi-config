# pi-config

This is my config for the [pi coding agent](https://pi.dev).

I initially had this in my various nix config repos but most of the files are the same between them and it became a pain to keep syncing the changes manually.

This repo has a couple of custom slop extensions to fix issues I had or implement improvements I wanted.

It also has [nix.nix](./nix.nix) and [home.nix](./home.nix) which is what describes my config and what I'll be importing in my NixOS and home-manager configs.
